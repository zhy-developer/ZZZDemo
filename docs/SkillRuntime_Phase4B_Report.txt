4. 输入、施放和帧阶段契约

延续4A，k是本次施放逻辑帧，新施放k=0；D-1移动/结算后才正常退出。
旧Animator结束、Clip切换、表现实例结束均不能自行结束Cast。
本帧先评估已同步输入，再消费已缓存意图，然后逻辑移动双方，获取统一快照，执行3C候选/解析/整批提交/退出，最后消费表现请求。
门控由冻结配置的k边界直接判定；例如 preinput 所在帧的输入已经可以缓存，不等下一帧播放事件回调。
  k < pre：拒绝。
  pre <= k < ready：无已缓存输入时记录一条归属于旧Cast的意图，随后等待ready。
  k >= ready：当前新输入可立即选择下一段；没有新输入时，已有合法缓存于ready被消费。
  k >= linkEnd：连段窗口已关闭，新攻击选择起始段。
注意现有4A规则：ready帧若同时有新输入和旧缓存，新输入先处理并启动新Cast、清理旧缓存。本批未把这个行为改成“所有情况下第一条优先”。多分支优先级未新增。
移动取消使用已有 move 边界；切换/打断/死亡清理相应Cast意图，不清空可靠发送队列或原始网络帧。
每次连段切换新建CastKey；同一技能内部多Clip不换Cast。缺帧/重复帧不重复推进、结算或生成实例。
预输入在网络中到达太晚会按实际服务器逻辑帧资格处理；本批没有输入预测或基于渲染时间回填。

5. 多 Clip 和 Root Motion 数值契约

逻辑步长仍33ms，位置精度10000；旧JSON字段、烘焙格式、旧 RootMotionPlayback 未变。
片段必须从0连续排列，无空档/重叠；D为既有动画末EndFrame，跨度必须等于 ceil((trimEndUs-trimStartUs)*1000/(33000*speedPermille))。
源时间纳秒：min(trimEndUs*1000, trimStartUs*1000 + (boundary-startFrame)*33000*speedPermille)。
源微秒不提前取整，因此1503等千分速度仍保留非整数微秒。
每段从源累计位移减去trim起点累计值，再接续前段累计值；烘焙点间作精确有理数线性插值。
旋转使用4A已有冻结朝向表（比例100），与距离千分倍率一起保留分数，到世界累计位置才向0截断；相邻累计边界相减得到每帧位移，保留尾差。
BigInteger只在新采样模块用于分子/分母乘除，避免合法样本、倍率和分母组合发生long溢出；最终checked转long，原移动入口继续约束地图范围。
范围沿用Schema：0<=帧<=1000000；0<sourceLengthUs<=86400000000；0<speedPermille<=100000；距离倍率0<permille<=10000。零速/倒播/越界Seek/非法Trim拒绝。
末段映射裁到trimEnd；无外推和循环补位移。部分覆盖采用有效 endFrameExclusive 对应 coverageEndMs核对，不能误拿完整表总长核对。
显式 HoldAtCoverageEnd 静止尾段保持末位置；未确认覆盖区间拒绝。provenance缺失保留Warning，不能证明动画与烘焙来源相同。
兼容例外：单Clip完整范围1倍恒等映射按旧33ms采样边界消费最后量化样本，保留4A逐帧结果；动画源采样仍裁到真实Clip末端。
恒等旧表来源长度不一致且未验证时保留原兼容范围；非恒等映射或已验证来源长度差>1ms则拒绝。
所有HitBox/Repeat/防御/逻辑事件已是技能帧，不再随Clip变速进行二次缩放。

编辑器：SkillAnimationPreview 与运行时共享 SkillClipTime；SkillRootMotionPreview共享 SkillMotionTimeline。
诊断区域显示帧前k、帧后/命中k+1、该步位移及源结束时刻。角色姿态为边界k，橙色攻击XZ轮廓表示本帧位移后的命中位置，青色为配置的HurtCircle。
真实Animator只按该映射采样表现，不回读normalizedTime推进权威；不承诺复现旧Animator Transition混合。

逻辑门控：combo.preinput、combo.attack-ready、combo.move-interrupt、combo.link，使用原已验收逻辑资格。
VFX/SFX：整批提交后，按CastKey及稳定cue ID描述并触发；同资源可对应多个事件。同步 Resources.Load，无挂起异步请求或迟到加载回调。
命中反馈：3C HitFeedback/receipt保持权威描述。当前Normal1～5未配置hitVfx/hitSfx；若组里设置非空反馈资源，运行就绪明确拒绝，尚没有其附着/寿命适配器，不能称已支持通用命中特效。
未知/不支持配置明确诊断，不回退旧ATK；表现生成异常捕获后不会修改HP、命中或技能资格。

Root跟随逻辑根；Bone使用确切路径或唯一节点名，缺失/歧义诊断；World保存触发帧逻辑根位置/朝向变换，后续不跟随。Y仅用于表现。
特效实例化前检查组件白名单，拒绝脚本、Collider、Animator等不支持组件；不采用实例化后禁用业务脚本。
粒子以33ms手动推进，固定Cast/cue/子系统种子；支持当前资源的有限Birth/Death后代子发射器，拒绝外部引用/循环子发射器/碰撞触发/无界曲线寿命。
TimelineControlled 到End停止发射，已发粒子可在有界尾迹内继续；AutoComplete自然结束或maxLifetimeFrames到达即回收，不延长D。
