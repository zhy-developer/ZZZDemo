二、主要接口及数据所有权

RuntimeSkillCatalog：复制 SkillType、无敌/打断窗口、解析后的组伤害、硬直、XZ 击退和反馈资源 ID。
所有集合只读、成员为不可变值；不持有可编辑 DTO/ScriptableObject 引用。
伤害调用既有 SkillDto.ResolveDamage：ComboBaseDamage 或 Explicit，绝不二者相加。
非零击退 Y 报 KNOCKBACK_Y_UNSUPPORTED；非零 XZ 且 N<=0 报 KNOCKBACK_DURATION_REQUIRED。
运行能力检查失败返回错误，原数据保留；不自动修改导出数据，也不把 FinishSkill 猜成 Ultimate。
BattleReady 仍恒为 false，正式完整配置 Loader 的拒绝保护未放开，缺失 HurtBox 仍报告 Error。

CombatantSnapshot / CombatFrameSnapshot：外部 HP 所有者提供的一帧只读快照。
含帧号、修订号、双方 EntityKey、CastKey、同一份移动后几何快照、HP、旧硬直和旧击退计划。
本批只以非负 Int64 表达隔离计算输入/输出 HP；没有选定正式 CharacterHealthInfo 的适配方式。

CombatResolver.Resolve(runtime, snapshot, candidateOrder)：纯计算，返回不可变 CombatBatch。
可传候选排列用于验证顺序无关性，但必须是捕获的完整候选集合；不允许漏项、重复或外来候选。
TargetResolution：每个目标只有一行 ExpectedOldHP、TotalDamage、FinalHP、防御、硬直、击退和退出原因。
Accepted 保留每个有效组的完整来源；计算不写账本，也不派发表现。

CombatBatch.TryCommit(adapter, out receipt, out error)：唯一批量提交入口。
CombatCommitReceipt：成功后才返回；含稳定排序的目标结果、每个有效命中的 HitFeedback 和回合结果描述。
反馈保留帧、实体、CastKey、SkillID、HitGroupID、代表 HitBoxID 及 VFX/SFX 资源 ID；不加载或播放资源。

ICombatStateAdapter：正式 HP 所有者以后实现的最小原子适配边界。
本批唯一实现 TestStateAdapter 在 Tests/SkillRuntime/Phase3CChecks.cs；不是 Assets 内的新 HP 系统。
测试适配器校验整个不可变快照身份（含修订和全部状态），准备全部新行后一次替换状态。
这一实现用于证明接口和失败场景；不能视为正式玩家 HP 已经接线。

KnockbackPlan：不可变来源、首帧、结束帧、持续帧数、已固定的世界总位移。
DeltaAt(F) / CumulativeAfter(n) 只返回整数增量，不修改 RoleBase、Transform 或旧位移播放器。

三、防御状态表与有效命中

目标状态                     伤害/反馈/记账      新硬直/击退        普通命中打断
Ultimate 活动期间             全部拒绝            不产生             不打断
处于任意无敌窗口              全部拒绝            不产生             不打断
Normal 位于可打断窗口         接纳                按组配置合并       接纳即打断，即使硬直0
Normal 不在以上窗口           接纳（霸体）        不新增             不打断，致死仍死亡
无活动技能（Idle/移动）       接纳                按组配置合并       没有虚构的 Cast 打断

无敌优先于打断；全部窗口是 [StartFrame,EndFrame)。Ultimate 包含 D-1 最后有效帧。
有效命中要求有效双方身份、尚存活的基线实体、当前活动相交攻击盒、命中组资格和目标非无敌。
零伤害、零硬直、零击退仍可有效；不通过 Damage>0/HitStun>0 猜测资格。
无敌拒绝不消耗 Single、不刷新 Repeat、不反馈。已死亡快照不再发起或接受新命中。
同组实际相交盒继续按 Ordinal HitBoxID 选唯一代表，不改变 Phase 3B 几何、空间或去重规则。

四、硬直、击退及数值契约

逻辑时间仍使用 33ms；预览/渲染/AnimationEvent 不参与计算。
技能 D 仍是既有 durationFrames，Validator 要求连续 AnimationSegment 从0覆盖到D，拒绝空档和重叠。
技能首帧0；移动后捕获同一帧快照；多 Clip 保持 CastKey；末帧结算后 CompleteFrame 才退出。
动画、Animator 或 Root Motion 表现结束不替代施放生命周期。

硬直：F 命中 N>0 -> [F+1,F+N+1)。N0 保留旧硬直；本帧多个值和旧区间取最晚结束帧，不相加。
F100,N1 -> 101受限/102恢复；N3 ->101..103受限/104恢复。
已生效旧区间的起点保留；过期区间通过 Contains 返回 false，无需因为零效果另行清除。
死亡结果清除控制计划，不新建普通硬直或击退；命中记录/反馈仍留在本帧成功结果中。

击退：HitGroup.knockback 是攻击者局部 TOTAL 位移，单位仍10000/世界单位；Y 非零拒绝。
角色朝向仍为毫度，0朝世界+X、90000朝世界+Z；局部+Z是前方。
只用命中快照的角色朝向转换一次，不加入攻击盒自身 Yaw，不再按后续朝向转动已有计划。
复用 Phase 3B 的确定性单位有理旋转：Q96固定常量/Taylor24构造、Q48半角参数、精确有理矩阵；
角度归一化和轴向角行为不变。角度近似的能力边界仍与3B一致，不宣称任意角的超越函数精确值。
只将最终旋转后的总 X/Z 舍入到最近逻辑整数，精确半数远离0。
第 n 步累计值 trunc(WorldTotal*n/N)，每步取相邻累计差；对负数同样向0截断。
从 F+1 开始 N 帧；N帧增量之和严格等于已量化的 WorldTotal，没有累计尾差。

最大组选择按未旋转的局部 XZ 长度平方，平局按完整 HitCandidate 比较键取最小：
Frame、CastKey（含EntityKey）、Ordinal HitGroupID、TargetEntityKey、Ordinal HitBoxID。
方向、总位移、持续帧数始终取同一个获选来源。
新非零计划替换尚未执行的旧计划；外部已应用的位置保持不动；零击退保留旧计划。

范围：局部X/Z各在[-1e9,1e9]，局部平方和先转Int64再乘，最大2e18，小于Int64最大值。
单位旋转后每轴绝对值<=sqrt(2)*1e9；舍入后仍小于2e9，输出使用Int64。
旋转和比例乘积使用 BigInteger/有理数，不在 int 溢出后才提升；累计除法使用 BigInteger。
HP输入0..Int64.MaxValue；每组伤害是已校验非负Int32，汇总 checked Int64，先比较再减，防止负溢出。
硬直/击退时间端点和适配器修订号使用 checked；越界明确失败，失败发生在发布状态前。
最终角色坐标仍须满足3B几何范围；实际地图边界与位移应用留给Phase4，不在本批悄悄截断。

五、整批校验、提交、幂等和退出

调用顺序：
1. TryBeginFrame：只接受连续新帧；空操作可正常推进，缺帧和重复帧不推进。
2. StartAccepted：真正被接受的输入才建立新Cast；同帧切换后使用新Cast的防御/形状。
3. 外部逻辑移动 -> CapturePostMove -> 外部 HP 所有者提供同一份几何/Cast 对应的快照。
4. Resolve：检查完整候选和基线；收集全部有效命中，再按目标合并，计算死亡、Winner/Draw。
5. TryCommit：核验仍为该未结算帧、完整runtime基线、实体/当前Cast/几何引用、组资格。
   不允许同帧混用旧单命中 TryCommitAccepted 和新批量提交，也不混入已排队的手工退出。
6. 提前准备新账本、新提交列表、新退出集合和成功回执，所有可失败分配/算术在发布前完成。
7. 锁住runtime重入，调用适配器对全部外部状态做比较、准备、一次发布。
   适配器 false 或准备阶段异常：runtime不交换任何状态，返回receipt=null。
8. 适配器成功后，runtime只做不分配、不回调的引用交换并标记本帧已提交，才返回成功回执。
9. 仅成功后消费回执并 CompleteFrame，执行唯一退出及 CastKey 资源清理；失败必须重取基线/重算，不能推进。

适配器的明确前提：单逻辑线程、无并发/重入、false/throw 必须保持宿主状态不变。
模块不能替任意违反契约的第三方实现撤销它已经执行的部分写入；Phase4必须验证真实HP适配器同样先准备后发布。
本批故障注入覆盖“准备第一目标后异常”“发布前拒绝”和重入，测试实现没有在失败前写入第一方HP。
成功后的runtime发布没有外部代码调用。没有搭建跨服务、线程或通用事务系统。

每目标一次 ExpectedOldHP->FinalHP，不存在多个hit拿同一个旧HP逐笔比较的冲突。
先得到双方完整命中集合，任何一条致死也不取消该帧其余命中；双方致死唯一Draw。
同一batch重复提交返回false、receipt=null，不扣血、不记账、不二次发反馈。
已死亡双方下一帧不再次生成Draw。

退出优先级：Death > Interrupted > Completed。Replaced/Destroyed仍用于原有替换或会话销毁边界。
CompleteFrame按稳定Cast顺序退出一次，清除该Cast账本和所拥有句柄。
旧Cast迟到清理不会删除新Cast复用的句柄。当前帧已应用位移不回滚，未来事件不再从退出Cast产生。
本帧已收集事件仍仅为描述符，本批不决定正式AnimationEvent执行或清理真实输入队列。
成功回执和Committed输出在清账后仍可读取；旧组记录不跨施放保留。
状态摘要加入 batchCommitted，以区分同帧已提交和未提交状态；因此3B摘要值发生预期变化。
