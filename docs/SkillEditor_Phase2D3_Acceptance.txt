二、实现方式与边界

数据与编辑
- 唯一编辑数据源仍是 ComboData.skill.vfx / sfx。使用现有 VfxCue / SfxCue / CharacterSkillCatalog.resources。
- 没有修改 DTO、JSON Schema、Phase 1 Loader/Exporter/校验器。
- Scene VFX Handles 使用 SkillEditCommands.BeginGesture / Apply / EndGesture：拖动只改临时副本，松手前登记 Undo 后一次提交；Escape 取消。Inspector 仍走既有 SerializedObject 命令。
- 位移精度 10000，旋转毫度精度 1000，scalePermille 为既有统一缩放（非三轴独立缩放）。Inspector 回显量化后的保存值。
- 预览时钟、粒子模拟、音源状态绝不反向写入 SO。仅明确编辑操作改数据；自动保存 SO 不自动导出 JSON。

VFX 安全构建
- SkillVfxProxy.Validate 在构建之前检查完整组件树与组件引用。
- 只重建原生 Transform、ParticleSystem、ParticleSystemRenderer、MeshFilter、MeshRenderer。没有 Instantiate(业务 Prefab)，不执行其 MonoBehaviour 生命周期。
- 拒绝缺失脚本、MonoBehaviour、Animator/VFX Graph/TrailRenderer 等不在支持集合中的组件，以及外部组件/对象依赖。
- 碰撞、Trigger、External Forces、Lights、Prewarm 不支持可靠隔离/历史重建，明确拒绝。
- 子发射器必须是所属发射器的后代，引用映射到会话自己的组件。跨树引用和循环引用拒绝。
- 保留 Prefab 根的原缩放；事件设置其生成位置/朝向，子层级保持原局部变换。材质、网格只读共享，不修改原资产。
- 粒子 stopAction 改为会话实例的 None，禁用 playOnAwake，固定 cue ID 派生随机种子，避免业务回调和不确定种子。源 Prefab 不变。
- 没有调用正式特效池、正式音频管理器、伤害、网络、角色注册、AnimationEvent 或技能事件执行器。

绑定与 Seek
- 每帧严格 0.033 秒，Animation Trim/PlaybackSpeed 与已有动画采样一致。
- Root 跟随逻辑根；Bone 支持精确相对路径，短名仅在唯一匹配时接受；偏移按米应用，不继承 FBX 骨骼缩放。
- World 在事件 startFrame 的真实采样姿态与整数 Root Motion 位置取生成矩阵，然后保持世界位置。
- Seek 清除旧表现，从 0 帧按 33ms 逐帧重建：先采样角色/骨骼，再推进原生粒子。没有把移动发射器简单放到目标位置后一次快进。
- 固定种子、子粒子和世界空间/移动发射历史均通过实际 Unity 粒子状态检查。
- 暂停保留状态，粒子由手动 Simulate 控制；循环回绕销毁旧表现，按循环起帧重建。循环区间只是预览参数。
- 预览倍速只改变墙钟推进速度，不改 SO PlaybackSpeed 或逻辑帧长度。
- 这是粒子模拟状态级重建；依赖 Shader 全局 _Time、GPU 效果、摄像机/屏幕内容等外观不保证 Seek/暂停一致，界面有明确诊断。不能把该范围当作全资源视觉验收。
- 逐帧重建成本随帧数和资源复杂度增长；当前无历史快照缓存。预览安全上限 60000 逻辑帧，不用于权威战斗。

生命周期与打断
- TimelineControlled 在 endFrame 停止全部发射，现存粒子继续衰减；自然清空后销毁。防止不消失资源的编辑器兜底是 endFrame+900 帧（29.7 秒），到达时强制清理并诊断。
- AutoComplete 自然完成后清理，允许跨越技能结束；maxLifetimeFrames 是既有明确上限。循环粒子显示警告，并在该上限清理，不会无限残留。
- 收尾由独立 PresentationFrame 推进，技能 Frame 停在动画末尾，不修改技能总时长。
- 模拟打断：startFrame>=打断帧的事件不触发；Precast 立即清理；已经出现的 AttackCritical 按原生命周期继续收尾；剩余技能运动停止。
- 关键特效 startFrame 必须不早于最后 interrupt.endFrame。非法配置预览拒绝、Phase 1 校验阻止导出。
- 打断操作会暂停并重建指定帧，点击“播放”可继续观察/试听收尾；该行为是编辑器模拟，不改变正式战斗规则。打断后 Seek 回打断前再播放，会推进到指定打断帧再执行策略。
- Seek/重置/循环清理旧实例；切技能、关窗口、离开 Stage、脚本重载、进入 Play Mode、异常退出全部清理会话拥有的实例和订阅。
- 参数错误可保留隐藏的视觉会话供修改后恢复，但其 VFX/SFX 已清空；意外异常销毁整个会话。

SFX
- 每条事件拥有独立隐藏 AudioSource，2D，默认不使用任何正式 Mixer/音频管理器。只停止/销毁自己的音源。
- 在 Unity 2022.3.62f2c1 编辑模式实际验证了两个音源同时推进采样、各自音量、暂停停止采样、恢复继续、单独停止、会话关闭不停止外部音源。
- OneShot 自然音频长度与配置 endFrame 取较早边界；Loop 按显式 endFrame 有限结束。
- 音量按 volumePermille、fadeInFrames、fadeOutFrames 逐逻辑帧计算。
- StopImmediately：立即释放；PlayToEnd：继续到配置/自然结束。Loop+PlayToEnd 采用已有 endFrame 作为有限收尾边界；FadeOut 从打断时音量衰减，结束释放。
- 拖动 Seek 和逐帧静音。随后播放不补播已经跳过的 OneShot；仍在有效区间的 Loop 从对应偏移恢复。普通暂停恢复使用同一音源和采样位置。
- 单次 Editor 更新跨多帧时逐帧处理事件，并纠正仍在播放的音源偏移，避免卡顿后所有新音效都从零开始。
- 0.25/0.5/1/2 倍预览通过 AudioSource.pitch 同步音速，音调也改变；没有保调变速。压缩/流式音频的 Seek 精度受编解码包限制，显示诊断。
- 未加载完成的音频显示诊断，等待资源加载后重新 Seek/播放；本批不修改音频导入设置。
- 本轮自动测试证明原生 API 状态，不替代原工程设备上的主观听感、混音及延迟验收。
