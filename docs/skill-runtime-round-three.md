# 技能运行时第三轮：预输入、连段与表现事件

## 第一步交付范围

已接入预输入和连段逻辑、角色后续技能列表、编辑器提示与诊断显示。尚未编译、启动 Unity 或执行测试，全部交由用户人工验收。特效、音效和 Scene 表现事件预览属于接下来的步骤，本次尚未实现。

现有第一段技能的窗口与攻击盒不改动，`nextSkillId` 仍为空，因此默认对战不会自动出现第二段。`Skill_0.asset` 是另一套旧 Skill 数据类型，不是本编辑器的 SkillDefinition，不用作连段目标。

## 已确认的规则

- 所有窗口使用半开区间 `[startFrame, endFrame)`，逻辑帧间隔仍为 33ms。
- 技能期间只有释放该连段的入口按键能接段。其他按键忽略；按住不自动生成新指令。
- PreInput 内第一次有效按键占用一个缓存位；重复按键不叠加、不替换方向。方向记录该次输入的朝向，无有效方向时沿用角色朝向。
- 退出 PreInput 后缓存仍保留，等待 ComboExecute。进入 ComboExecute 即消费缓存；在 ComboExecute 内直接按键也可以接段。
- 每角色每逻辑帧最多开始一段，新段从 F0 开始并增加释放序号。同帧后续按键不再为刚开始的新段预输入。
- 连段优先于同帧移动取消；新段开始这一帧不会被持续移动输入立刻取消。下一帧恢复新段自身的 MoveCancel 判定。
- 切段时保留上一段已经经过的 `[F-1,F)` 位移一次，取消其之后的位移和攻击区域；新段 F0 不额外消费根位移。
- 受击、移动取消、自然结束、切段和对局结束均清空旧缓存。技能自然结束后再次按键从入口段开始。
- 切段发生在当帧攻击区域采集之前。因此切段帧检测新段 F0；命中采集完成后，仍统一结算双方同帧已经成立的命中。
- 空目标表示该窗口不接段；非空目标必须存在于本角色技能库。重叠的 ComboExecute 窗口属于配置错误；循环连段允许，但必须每次收到新输入。

## 职责

| 脚本 | 职责 |
| --- | --- |
| SkillCombatProfile | 保存入口按键绑定与 Additional Skills 后续技能列表 |
| CombatSkillLibrary / CombatSkill | 开局克隆配置、按 ID 查找、验证目标引用、查询窗口和位移 |
| CombatSkillInput | 接收技能按键、保存一次预输入、消费缓存并开始下一段 |
| CombatFighter | 保存入口指令、缓存标记与朝向；统一清除离开技能后的缓存 |
| CombatWorld | 按边界推进 → 收输入 → 接段 → 位移 → 收集命中 → 结算的顺序调度 |
| SkillValidation | 提示未填写目标、非连段窗口误填目标、执行窗口重叠 |
| CombatStatusView | 显示释放序号和缓存状态，状态摘要包含连段相关状态 |

动画、移动 FSM、位置 SmoothDamp 仍在渲染帧推进；本步未改动表现时钟。顿帧保持关闭。

## 人工配置与验收

1. 创建新的 SkillDefinition 后续段资产，在技能编辑器填写唯一技能 ID，配置动画、根位移、命中组和手动摆放的攻击区域。需要先验证输入衔接时，可复制第一段作为临时后续段并更换 ID；它仍然是同一动画的临时配置，不代表正式普攻第二段。
2. 将后续段拖入 `Unagi_CombatProfile` 的 `Additional Skills`。`Commands` 中普通攻击继续只绑定第一段。
3. 在第一段 `ComboExecute` 的“下一段技能”下拉框中选择后续段，保存的仍是 `nextSkillId`。选项来自注册了当前技能的角色配置（合并 Commands 和 Additional Skills）；多个来源时可切换“注册来源”，但共用技能的目标需在各来源中都注册。重复或空 skillId 不提供选择，失效的当前值保留并提示。“无”用于清空目标。PreInput 和 MoveCancel 不显示目标选择。后续段也可按相同方式配置再下一段。
4. 两端重新开局加载同一配置。第一段当前 PreInput 为 `[7,14)`，ComboExecute 为 `[17,19)`：在 F7～F13 再按一次，HUD 应显示“缓存：有”，到 F17 切段；F14～F16 的新按键无效；无缓存时 F17/F18 按键也应切段，F19 不应切段。
5. 连续多按只能产生一次缓存；一帧的多个网络操作不能跳过多个技能。新段需要新的有效按键才能再次接段。
6. 在 F17 同时满足移动和连段时，应优先接段；没有有效连段时按原 MoveCancel 配置恢复移动。取消后缓存应为空。
7. 缓存后被击中，应进入受击并清空缓存；硬直结束不应自动补放。自然结束和对局结束也不保留缓存。
8. 双端核对同一逻辑帧的状态摘要、技能 ID、释放序号、缓存与位置。同帧互相命中依然各自结算。
9. 将目标改为不存在的 ID 或配置重叠执行窗口，应有明确错误并阻止开局；目标留空只提示且不接段。恢复配置后重新开局。
10. 人工观察不同渲染帧率下移动和技能动画的连续性；逻辑帧决定切段，不能让动画或平滑位置退回每 33ms 一次更新。
11. 在技能编辑器和资产 Inspector 分别打开 ComboExecute，确认均可下拉单选目标、清空和撤销。修改注册列表或 skillId 后重新查看，确认选项刷新；取消注册当前目标后，旧 ID 应保留并显示不可用提示，不能自动改为另一项。
